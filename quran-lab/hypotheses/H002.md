# H002 : « le mot `عقل` n'apparaît que sous forme verbale »

- **Date d'écriture** : 2026-10-14 (commit « prereg: H002 » AVANT tout calcul de ce test)
- **Statut de départ** : AFFIRMATION POPULAIRE
- **Source de l'affirmation** : circule dans des discussions sur le vocabulaire de la raison en arabe coranique ; source primaire non retrouvée.

## Hypothèse
Dans le texte coranique de référence (Tanzil), aucun mot construit sur les lettres `عقل` n'est un nom (« raison » ou dérivés) : toutes les formes sont des verbes.

## Définition opérationnelle
- Texte : simple-clean **et** Uthmani, tokens ramenés au squelette (`normalize.skeleton`).
- Candidats : tout token contenant la séquence `عقل`.
- Classement par expressions régulières **fixées ici** :
  - **verbal** : `^[وف]?[يتن]عقل(ون|وا|ها|ه|ان|ن)?$` (inaccompli) ou `^[وف]?عقل(وه|وها|وا)$` (accompli avec pronom) ;
  - **nominal** : `^[وف]?[بلك]?(ال)?(عقل|عقول|عاقل|عاقلة|معقول)(ا|ي|ك|هم|ه|ان|ين|ون)?$` (inclut la forme nue `عقل`, qui est ambiguë : elle est classée nominale pour ne pas favoriser l'hypothèse) ;
  - **autre** : tout token candidat hors de ces deux classes, **listé**, jamais ignoré.

## Statistique et verdict (fixés ici)
- Décompte de chaque classe, par orthographe.
- Verdict :
  - `nominal = 0` et `autre = 0` → `REPRODUIT` (sur ce périmètre) ;
  - `nominal = 0` et `autre > 0` → `PARTIEL` (les formes « autre » doivent être classées à la main) ;
  - `nominal > 0` → `NON REPRODUCTIBLE`.
- Statut maximal : `DÉPEND DE LA RÈGLE` (le classement est une approximation morphologique ; la morphologie réelle le confirmera ou non). `ROBUSTE` interdit.

## Modèle nul et famille
Aucun modèle nul : c'est une vérification d'existence (une forme existe ou n'existe pas). Famille `F-existence`, taille 1.

## Ce que l'auteur sait avant d'écrire ce fichier
Aucun décompte de ces formes dans le texte de référence. L'auteur a une attente de mémoire (formes verbales fréquentes) qui n'a pas valeur de fait.

## Limites
Le sens n'est pas distingué ; la forme nue `عقل` pourrait aussi être un verbe à l'accompli (classée nominale par prudence) ; approximation de la morphologie.
